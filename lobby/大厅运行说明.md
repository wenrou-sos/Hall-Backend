# SD555 平台大厅本地化运行说明（打桩版 · 部分跑通）

> 目标：用备份原版代码跑平台大厅。当前已跑通**平台后端三件套 + 大厅 H5 启动 + guest 登录 + WS 协议链路**；
> 大厅主界面（游戏列表 UI）因手游 res 资源管线/懒加载模块依赖尚未完整渲染，属未完成部分，见「边界」。

## 一、架构与端口
| 组件 | 端口 | 来源 | 说明 |
|---|---|---|---|
| local_redis.py | 6379 | 自写打桩 | 最小 RESP2 服务，替代死掉的 GCP Redis(34.80.168.83) |
| stub_apiserver.py | 81 | 自写打桩 | 替代原版 Python apiserver（其依赖 CloudSQL/Firebase/远程PS，且 **SD555 MySQL schema 不在任何备份中**） |
| lobbyserver（原版） | 80 | GitLab `sd555-app/lobbyserver` | 原版 Python WS 大厅服务，仅依赖 Redis+apiserver HTTP，不依赖 MySQL |
| 大厅前端（原版） | 8082 | GitLab `sd555-app/sd555-app-lobby` | Cocos2d-html5 v3.17 H5，serve 于短路径 `D:\lobby_fe`（避开 Windows MAX_PATH） |
| 捕鱼游戏（已完整跑通） | 8080/8899 | 见 fish/运行说明.md | 大厅最终要跳转的目标游戏 |

## 二、已验证跑通的链路
1. 前端引擎 boot（补 13 个缺失引擎文件 + sdkbox/jsb 全局桩 + spine 空骨骼守卫）
2. WS 连接 lobbyserver:80（`GET /lobbyserver → 101`）
3. serverinfo 回包（serverstate/rerobject 等字段）→ 通过维护/版本检查
4. **guest 登录成功**：LoginCall→LoginRecall statuscode 0，memberid=10001/DEV/coin 99999，发 logintoken
5. LobbyScene 可 push、PageController 可构造（jsList 模块图加载后）

## 三、打桩/补丁清单
- `lobbyserver/pg_redis.py`：aredis→redis.asyncio；Redis host→127.0.0.1
- `lobbyserver/pg_ga.py`、`glogger.py`：去 pyga/GCP logging，改本地 no-op/logging
- `run_lobby.py`：bundled python 为隔离模式，手动注入 sys.path 启动 lobbyserver
- `stub_apiserver.py`：按原版契约 `{apiresult,serverdata,clientdata}` 实现 login/getgamelist/joingame/serverinfo/getmyip 等
- 前端 `src/build_setting.js`：URL_LobbyServerUrl→ws://127.0.0.1:80/lobbyserver；URL_GetIP→本地
- `D:\lobby_fe\index.html`：注入错误收集 + sdkbox/jsb 递归 no-op 桩
- spine 引擎（CCSkeleton/CCSkeletonAnimation/RenderCmd）：空骨骼/空 state 守卫，web 下骨骼视觉可缺但不中断逻辑
- 引擎缺失文件：从捕鱼客户端 frameworks 补 13 个 404 文件

## 四、边界（未完成）
- 大厅主界面各层（ly_club/ly_game_board 等）ctor 依赖**手游 res 资源管线**（native searchPaths/hotupdate），web 下部分 res 未加载导致 ctor 抛错；需逐层补 res 或加容错，工作量大
- 原版 apiserver 无法忠实运行：**SD555 MySQL schema/数据不在备份中**（原在 Cloud SQL），故用 stub 替代
- 因此「大厅里点游戏列表→进捕鱼」的完整 UI 链路尚未闭环；捕鱼本身可独立直连玩（8080）

## 五、启动
双击 `启动大厅后端.bat`（起 redis/stub-api/lobbyserver/前端），浏览器开 http://127.0.0.1:8082/。
guest 登录可在控制台调 `SW.model.login('devdevice001',null,null,null,function(){},0)`。
捕鱼独立玩：见 `fish/运行说明.md`（8080 前端 + 8899 服务端）。
